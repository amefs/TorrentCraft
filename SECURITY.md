# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's private
vulnerability reporting or security-advisory facilities. Do not disclose
unresolved security issues in a public issue or pull request.

Include the affected version, platform, build configuration, reproduction
steps, and any relevant logs. Please avoid including personal data or private
keys in the report.

The maintainers will acknowledge a report when practical, investigate it, and
coordinate a fix and disclosure timeline with the reporter.

Supported versions and release-specific security notes are listed on the
repository's Releases page.
