# 总览

TorrentCraft 是一套现代化、高性能的 BitTorrent 种子制作与管理工具包。无论是通过终端脚本自动化，还是在桌面端直观操作，它都能提供高效、可靠的体验。

## 两种使用方式

- **[CLI 命令行工具](/zh/cli/)**——轻量高效的命令行程序（`torrentcraft`），专为终端用户、自动化脚本、批量任务以及 CI/CD 流程设计。支持标准易读的文本输出、严格稳定的 JSON 输出以及 Shell 自动补全。
- **[桌面 GUI 客户端](/zh/cli/gui)**——基于 Qt 开发的现代化图形界面程序（`torrentcraft-gui`），支持可视化文件选择、拖拽操作、实时进度反馈和便捷的配置管理。

两套工具共用同一套底层核心引擎与统一的配置文件（`torrentcraft.json`），无论在命令行还是桌面端操作，都能获得完全一致的处理逻辑和配置体验。

## 核心功能

- **制作种子（Create）**：支持从单个文件或整个文件夹生成 V1、V2 以及兼顾新旧客户端的 Hybrid（混合）格式种子；支持自动或自定义分块大小（Piece Size）及灵活的文件排序规则。
- **查看与浏览（Inspect & Tree）**：无需下载或读取原始数据，即可秒级解析种子元数据、Info Hash（SHA-1 / SHA-256）及层级折叠的文件目录树。
- **内容完整性校验（Verify）**：高效比对本地文件与种子内容是否一致，支持多线程并发哈希计算与内存占用限制。
- **种子格式校验（Validate）**：快速检查种子文件本身的语法正确性与规范合规性。
- **安全修改元数据与 Tracker（Modify & Tracker）**：支持在不重新哈希文件的情况下，安全更新 Tracker 服务器列表与层级、注释、发布者信息、Web Seed 等；内置自动备份与 Dry-run（试运行）防错机制。
- **统一配置与预设模板（Config & Presets）**：可将常用的制作参数（如常用 Tracker 列表、Piece 大小、私有种子标记等）保存为命名预设，随时一键调用。
