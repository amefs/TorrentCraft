# CLI 使用指南

`torrentcraft` 是一款功能强大、轻量高效的命令行工具。它默认输出格式清晰、易于阅读的控制台文本，同时支持通过参数输出标准稳定的 JSON 数据，非常适合日常终端操作、自动化脚本编写以及 CI/CD 自动化流水线。

如果您更喜欢图形化界面，请参阅[桌面 GUI](./gui)。

## 命令速查表

| 命令 | 说明 |
| --- | --- |
| [`create`](./create) | 从文件或文件夹制作全新的 V1、V2 或 Hybrid 格式种子。 |
| [`inspect`](./inspect) | 解析并展示种子文件的元数据、Info Hash 及校验兼容性能力。 |
| [`tree`](./tree) | 以树状图直观展示种子内部包含的目录与文件层级。 |
| [`verify`](./verify) | 比对本地文件与种子定义的数据，校验文件完整性。 |
| [`validate`](./validate) | 快速校验 `.torrent` 文件本身的语法与规范合规性（无需读取实际数据）。 |
| [`tracker`](./tracker) | 查看、添加、删除或批量替换种子中的 Tracker 服务器列表与层级。 |
| [`metadata`](./metadata) | 查看、修改或清除种子中的附加元数据（如注释、制作者、来源、私有标记等）。 |
| [`config`](./config) | 查看、初始化及修改全局共享的 `torrentcraft.json` 配置文件。 |
| [`preset`](./preset) | 管理常用的命名预设模板，快速复用制作参数。 |
| [`completion`](./completion) | 生成 Bash、Zsh 或 Fish 的 Shell 自动补全脚本。 |

> **智能路径推断**：如果传入的第一个参数不是命令名，而是文件或文件夹路径，TorrentCraft 会自动智能推断你的意图并执行相应操作（例如直接运行 `torrentcraft demo.torrent` 会自动执行查看操作）。详见[路径推断](./path-inference)。

## 全局帮助与版本查询

```bash
# 查看全局帮助和可用命令列表
torrentcraft --help

# 查看当前安装的版本号
torrentcraft --version

# 查看具体某个子命令的详细选项与使用示例
torrentcraft <command> --help
```

## 通用命令行规范

TorrentCraft 的所有子命令均遵循一致、规范的 Unix 命令行设计理念：

- **标准流分离**：命令执行的核心结果与主要数据输出到**标准输出（stdout）**；进度条、状态提示与诊断日志输出到**标准错误（stderr）**，便于通过管道或重定向轻松捕获结果。
- **结构化输出**：绝大多数命令均支持 `--json` 参数，返回结构固定的 JSON 响应数据包（如 `{"ok": true, "data": ...}`），便于脚本程序解析。
- **静默模式**：支持 `--quiet` 参数，在执行成功时隐藏多余的提示信息，仅保留关键状态。
- **安全防误触机制**：
  - 创建类操作默认禁止直接覆盖已存在的文件，需显式添加 `--overwrite` 参数。
  - 修改类操作支持 `--dry-run`（试运行，仅模拟校验而不实际修改文件）与 `--backup`（修改前自动创建原文件的 `.bak` 备份）。

建议先阅读[开始使用](./getting-started)了解基础上手流程，或直接点击上方表格中的命令查看详细参数说明。
